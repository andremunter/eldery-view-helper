# Eldery View Helper

https://github.com/viktor-parment/hildur-hjortronet-helper.git

Fortsätt projektet.
Vi måste lägga till en "Pensionärs-vy" där all text är enorm, så även en i princip blind kan se.
På startsidan ska det komma upp en overlay där man får välja:
SYNPROBLEM? TRYCK HÄR! 
eller (fortsätt till vanliga sidan)
Synproblemknappen ska vara jätteliten, (fortsätt till vanliga sidan) ska vara stort
